# Inverteum Capital

We are a quantitative investment firm. Data and code are how we understand markets.

We do pro bono work on open source projects.

### Open source projects we've contributed to

- [planning-with-files #388](https://github.com/OthmanAdi/planning-with-files/pull/388) (28K⭐) — A file-based planning tool for AI coding agents, with crash-proof markdown plans and a completion gate.
- [core-js #1590](https://github.com/zloirock/core-js/pull/1590) (26K⭐) — A library that helps modern JavaScript work the same way in different browsers.
- [super-productivity #11858](https://github.com/super-productivity/super-productivity/pull/11858) (24K⭐) — A cross-platform to-do list and time tracker with recurring tasks, time tracking, and sync.
- [pr-agent #5038](https://github.com/The-PR-Agent/pr-agent/pull/5038) (17K⭐) — A pull-request reviewer that comments on code changes and suggests improvements.
- [repowise #5940](https://github.com/repowise-dev/repowise/pull/5940) (8K⭐) — A local codebase index that maps architecture, code health, and git history for coding agents and developers.
- [Agentero #1224](https://github.com/poco-ai/Agentero/pull/1224) (3K⭐) — A unified research workspace for humans and agents, with PDF Q&A and citations.
- [Brighter #4763](https://github.com/BrighterCommand/Brighter/pull/4763) (2K⭐) — A .NET command processor and messaging framework for sending and handling commands, in-process or across services.
- [crosstl #4870](https://github.com/CrossGL/crosstl/pull/4870) (2K⭐) — A translator for GPU shaders and compute kernels across GLSL, HLSL, Metal, SPIR-V, Slang, CUDA, HIP, and WGSL.
- [couch-tv #275](https://github.com/Seagey/couch-tv/pull/275) (2K⭐) — A phone-controlled TV home screen and remote that replaces the built-in smart-TV interface.
- [rockpack #126](https://github.com/AlexSergey/rockpack/pull/126) (1K⭐) — A toolkit for starting React websites quickly, with little setup, server-rendered pages, and automatic code checks.
- [dreamcoder #285](https://github.com/GoDiao/dreamcoder/pull/285) — A locally run, multi-provider AI coding workspace.
- [lgpd-skills #12](https://github.com/goul4rt/lgpd-skills/pull/12) — A toolkit of agent skills for LGPD privacy auditing and engineering in software projects.
- [ctxvault #62](https://github.com/Filippo-Venturini/ctxvault/pull/62) — Local memory for AI agents, organized into vaults you compose, control, and query.
- [dataprof #1372](https://github.com/AndreaBozzo/dataprof/pull/1372) — A data profiler for CSV, JSON, Parquet, and DataFrames, with a Rust core and a Python API.
- [goldener #460](https://github.com/goldener-data/goldener/pull/460) — A Python library for data-centric orchestration across the AI lifecycle.

### Projects

- [Command Line Solitaire](https://www.inverteum.com/coding/solitaire-command-line/) — For those who prefer playing Solitaire in Terminal.
- [10-Year Return Calculator](https://www.inverteum.com/coding/10-year-return-calculator/) — See how common allocations, including a 60/40 portfolio, would have performed over 2016-2025.
- [Returns Calculator With Cash Flow](https://www.inverteum.com/coding/returns-calculator-with-cash-flow/) — Calculate time-weighted and money-weighted (Modified Dietz) returns that take contributions and withdrawals into account.
- [Recovery Time and Gain After Drawdown](https://www.inverteum.com/coding/calculate-recovery-time-and-gain-for-drawdown/) — See how much of a gain it takes to get back to even after a loss, and how long that recovery would take at an assumed return.
- [Time Clock](https://www.inverteum.com/coding/time-clock/) — A browser-based time clock: clock in and out by name, see who's clocked in, a leaderboard, and a CSV export. Records are saved in this browser, so they survive a refresh or memory-saver.
